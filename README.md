# MANIT Find

**MANIT Find** is a college lost-and-found website I created to help MANIT students report lost items and find their belongings.

🌐 **Live Website:** https://friendly-gumdrop-0a2b54.netlify.app/

## Features

- Report lost and found items
- Browse and search item reports
- Filter reports by Lost and Found
- View complete item details
- Admin-only feature to mark reports as resolved

## Technologies Used

- HTML
- CSS
- JavaScript
- Supabase
- Netlify

## Project Purpose

The purpose of MANIT Find is to provide students with a simple and accessible platform to report missing belongings and connect with people who may have found them.
